# Welcome to your molstem thermocycler

The **molstem thermocycler** is a professional-grade portable PCR thermocycler designed for point-of-care diagnostics, field research, and laboratory applications.

## Key Features

- **Rapid Thermal Cycling** — Complete protocols in under 45 minutes with precise temperature control
- **Compact & Portable** — Lightweight design suitable for field deployment and benchtop use
- **Smart Connectivity** — Local network access or cloud integration for remote monitoring
- **Real-time Monitoring** — Track temperature profiles live during experiments

## Setup Wizard

This wizard will guide you through:

1. **Device Configuration** — Set your device name and access credentials
2. **Network Connection** — Connect to your WiFi network
3. **Registration** — Complete setup for local or cloud operation

Your device will be ready for use in just a few minutes.
